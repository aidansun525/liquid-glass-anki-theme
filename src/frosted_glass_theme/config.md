Background settings. The easier way to change these is **Tools → Frosted Glass → Settings…**, which applies changes live.

- **Image name for background**: a file in `user_files/background`, or `random`.
- **Image name for gear**: a file in `user_files/gear`, `random`, or `gears.svg` for Anki's own icon.
- **background opacity main / review**: 0 to 1.
- **background scale**: zoom, 1 = no zoom.
- **background-size / position**: CSS values.
- **Reviewer image / Toolbar image**: show the wallpaper on the review screen / the top and bottom bars.
- **New wallpaper on each visit to the deck list**: rotate automatically.
