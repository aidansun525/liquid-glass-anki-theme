# Changelog

## 1.1

- Fixed: the glass card flashed every time a new card appeared on some PCs. The card now stays on screen and only its text changes.
- Fixed: the card didn't keep the height you set. It now stays at exactly that height on every card, and a long card scrolls inside it instead of stretching the panel. Very tall settings are limited only by the size of the window.
- Set Card height all the way left ("Fit to card") if you'd rather the card size itself to each card, as before.

## 1.0 (first public release)

- A wallpaper behind every screen, lined up seamlessly across the top bar, main screen and bottom bar.
- Daily wallpapers: professional photos (Nature, Architecture, Landscape, or your own tags) or safe-rated anime art from Konachan and Wallhaven.
- Four built-in wallpapers (film photographs by Aidan S.).
- A frosted-glass review card with adjustable opacity, blur, width, height and corners.
- A soft glow and piano note on each answer, with adjustable volume.
- A card text size slider.
- One Settings window where every change applies live.
