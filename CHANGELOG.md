# Changelog

## 1.4

- New: move the card up or down (Settings → Glass & sound → Distance from top).
- New: a soft piano chime, in the same tone as the answer notes, when you finish a deck. It plays only when nothing is left to study, not when you leave early, and follows the Piano note switch, volume and speaker choice. Put your own `finish.wav` in the sounds folder to replace it.

## 1.3

- New: choose which speakers or headphones play the piano note (Settings → Glass & sound → Play on). If the one you picked isn't connected, the system default is used.

## 1.2

- Fixed: the card and glass panel still flashed when a new card loaded on some Windows PCs. The frosted glass is now its own layer behind the card, so loading a card never redraws it, and the new card's text simply replaces the old one instead of blinking out first.

## 1.1

- Fixed: the glass card flashed every time a new card appeared on some PCs. The card now stays on screen and only its text changes.
- Fixed: the card didn't reach the height you set when your Anki window was small, because it was capped at 82% of the window. The card height you set is now the minimum on every card, up to the full height the window allows. Longer cards still grow past it.
- Switching between installing from a file and installing with the AnkiWeb code no longer starts you over. The copy you install last brings over the other copy's settings and pictures, turns the other copy off, and tells you so. Updating the same copy keeps everything too, as before.
- New built-in wallpapers in later versions are added to your collection on update, but one you deleted never comes back.

## 1.0 (first public release)

- A wallpaper behind every screen, lined up seamlessly across the top bar, main screen and bottom bar.
- Daily wallpapers: professional photos (Nature, Architecture, Landscape, or your own tags) or safe-rated anime art from Konachan and Wallhaven.
- Four built-in wallpapers (film photographs by Aidan S.).
- A frosted-glass review card with adjustable opacity, blur, width, height and corners.
- A soft glow and piano note on each answer, with adjustable volume.
- A card text size slider.
- One Settings window where every change applies live.
